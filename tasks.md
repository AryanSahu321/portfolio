### [ ] Task 6: Learn & Master Practical Interview Q&As for Tools Used in Projects

> _Focus specifically on how these technologies were utilized in your projects so you can explain them clearly and confidently in interviews without getting overwhelmed by theoretical internals._

- [ ] **Celery (Task Queue):**
  - _Interview Q:_ "Why did you use Celery in your Land Acquisition platform?"
  - _Core Answer:_ Used for offloading heavy, time-consuming geospatial risk calculations and survival analysis models into asynchronous background worker tasks so the user's browser API request doesn't timeout or freeze.
- [ ] **FastAPI (Backend Web Framework):**
  - _Interview Q:_ "Why FastAPI over Flask or Express?"
  - _Core Answer:_ Native async/await support, automatic interactive Swagger/OpenAPI documentation, high execution speed with Pydantic data validation.
- [ ] **PostgreSQL & PostGIS (Spatial Database):**
  - _Interview Q:_ "What was PostGIS used for in the project?"
  - _Core Answer:_ Storing geographic polygons and spatial coordinates of national highway corridors to execute geometric intersection queries (e.g. checking whether proposed land overlaps with forest reserves or water bodies).
- [ ] **Docker & Linux:**
  - _Interview Q:_ "How did you use Docker?"
  - _Core Answer:_ Used `docker-compose.yml` to bundle the multi-container environment (FastAPI API server, PostGIS database, and Redis/Celery workers) ensuring consistent development environments across local and Linux cloud servers.
- [ ] **PyTorch & Hugging Face:**
  - _Interview Q:_ "What was PyTorch's role in your Fake News project?"
  - _Core Answer:_ Handled transformer tensor computations, GPU memory allocation, and gradient backpropagation during fine-tuning of DeBERTa and DistilBERT on the 72k WELFake dataset.
- [ ] **Mermaid.js:**
  - _Interview Q:_ "How do you use Mermaid.js?"
  - _Core Answer:_ To draft visual system architecture diagrams, database schemas, and request-response flowcharts directly inside project Markdown files for clear technical documentation.
